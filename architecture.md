# Architecture

React 19 application with Vite 8 and Tailwind. src/App.tsx contains the exported interface; src/index.css defines the existing PCB visual design. index.html mounts src/main.tsx.

Planned: verified project content in src/data/projects.ts, generated proof manifest from public/proof, accessible galleries and case study dialogs, shared data for UART commands, and Amplify deployment of dist.

The export establishes layout. Actual repositories and the earlier portfolio establish facts. Recordings must be labeled RECORDED and simulations DEMO.
